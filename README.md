# Native Frame Interpolation Extension for SwarmUI

An extension for [SwarmUI](https://github.com/mcmonkeyprojects/SwarmUI) that adds native frame interpolation capabilities (VFI) to video workflows and history viewer.

## Features
- Direct frame interpolation with customizable multipliers and FPS adjustments.
- Integration with ComfyUI's native frame interpolation model loader and execution pipeline.
- Interactive action button in SwarmUI's image/video history view to easily interpolate generated videos.
